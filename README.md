## 🧭 My Mission

I focus on building practical software that prioritizes **security, privacy, data ownership, and local control**.

My goal is to develop applications that can operate on systems and servers controlled by their users, minimize unnecessary external dependencies, and make sensitive data handling more transparent.

- 🖥️ **Local-first:** Prefer processing and storage on user-controlled systems.
- 🛡️ **Security-conscious:** Apply authentication, authorization, validation, and secure defaults where appropriate.
- 🔒 **Data protection:** Consider encryption, integrity checks, backups, and access restrictions.
- 🔄 **Controlled updates:** Prefer deliberate, documented updates over unnecessary background changes.
- 🌐 **Self-hosting:** Explore deployments that reduce dependence on third-party platforms.
- 🧰 **Practical engineering:** Build maintainable tools for real-world problems.
